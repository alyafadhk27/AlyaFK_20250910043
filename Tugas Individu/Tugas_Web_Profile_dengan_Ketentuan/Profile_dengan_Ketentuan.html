Tentang Saya

Halo! Saya Alya Fadhilah Kamal, seorang mahasiswa aktif Program Studi Sistem Informasi di Universitas Kuningan. Saya memiliki ketertarikan tinggi pada analisis teknologi informasi, manajemen data, dan pengembangan organisasi.

Di luar kesibukan kuliah dan organisasi di HIMASI, saya sangat menyukai olahraga berenang untuk menjaga kebugaran fisik dan menyegarkan pikiran. Saya juga selalu menghargai waktu luang untuk berkumpul bersama keluarga tercinta.

Pengalaman Organisasi

Himpunan Sistem Informasi (HIMASI)
